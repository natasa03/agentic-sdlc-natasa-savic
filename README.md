# Agentic SDLC: Building a Software Factory

This course walks through building a suite of AI agents that automate each phase of the software development lifecycle — from requirements and architecture through to testing and deployment. By the end, every major SDLC activity has a dedicated agent, and they work together as an automated software factory.

## 🏗️ Course Modules

- [ ] **Module 1** — Git Workflow Agent: automate GitHub Issues, feature branches, commits, and Pull Requests using `gh` CLI and strict conventions
- [ ] **Module 2** — Software Architecture Agent: generate arc42 architecture documents and C4 model diagrams (Context, Container, Component) from project context
- [ ] **Module 3** — Software Requirements Agent: derive user stories, model domain concepts with DDD, and prioritise requirements using the Pareto principle
- [ ] **Module 4** — CI/CD Deployment Pipeline Agent: generate and manage GitHub Actions workflows and AWS SAM deployment configurations
- [ ] **Module 5** — TDD/BDD Multi-Agent Test System: orchestrate a four-agent red-green-refactor loop (test writer, executor, implementer, refactorer)
- [ ] **Module 6** — Final Project: individual kata applying all five agents end-to-end on a real feature from requirements to deployed, tested code
